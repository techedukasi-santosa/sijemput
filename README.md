# sijemput
SiJemput Siswa adalah aplikasi penjemputan siswa yang aman, cepat, dan terintegrasi. Menggunakan QR Code, verifikasi data penjemput, notifikasi otomatis kepada orang tua, serta riwayat penjemputan secara real-time. Membantu sekolah meningkatkan keamanan, ketertiban, dan efisiensi proses kepulangan siswa setiap hari.
